## 👨‍💻 About Me

I'm a **Fullstack Web Developer** based in Sydney, Australia, passionate about building practical software and understanding how things work under the hood.

🎓 **Certificate IV in Web Development — TAFE NSW**

💼 **Currently working on modernising a 20-year-old WinForms CRM application into a modern full-stack web application**, helping transform a long-standing desktop system into a scalable and maintainable web-based platform.

🔧 Working across the stack with **React, TypeScript, .NET, C#, ASP.NET Core, REST APIs, SQL and Entity Framework Core**, while also contributing to architecture, system design, testing and debugging.
